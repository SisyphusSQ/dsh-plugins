# dsh-ui-zoom

[English](README.md) | 中文

DeepSeek Harness 整体界面缩放插件：既可用快捷键驱动，也有设置页入口。

目标版本 `@deepseek-ai/dsh@0.2.0-rc.2`。

## 它能做什么

DeepSeek Harness 自带的排版控制只有一个「外观 → 字号大小」，而且它**只作用于会话内容**（`--dsh-content-font-size`，10–22 px）。侧边栏、设置页、按钮和菜单读的是另一套固定的 `--dsw-*` 令牌，没有任何东西会缩放它们。

本插件缩放的是**整个界面**，范围 50%–300%，入口是**设置 → 通用 → 整体界面缩放**：该行显示当前百分比，带 −/+ 按钮和重置。设置是持久的——它存在 Host 的用户设置文档里，因此重启后保留、并跟随 profile。

## 缩放是怎么实现的

文档元素上写入一个 CSS `zoom`：

```css
:root { zoom: 1.25 }
```

有两个细节是刻意的。

**挂在文档元素上，而不是应用根节点。** 菜单、弹窗、悬浮卡片、toast 和灯箱全部通过 `createPortal` 挂到 `document.body`。如果规则只作用于 `#root`，所有浮层都会保持原尺寸不变，所以缩放要挂高一层，让整个页面都在它里面。

**用 `zoom` 而不是 `transform: scale`。** `zoom` 会成倍地改变实际使用值，因此布局、命中测试、锚点定位和拖拽区域都在同一个坐标系里解析。`transform: scale` 会让布局计算停留在未缩放空间，并为 fixed 定位的后代新建包含块。

Host 半边通过 `webserver/index-inject` 在任何浏览器插件启动前注入样式表，因此首屏就已经是缩放后的画面，不会先闪一下 100%。

## 配置

插件拥有 `ui-zoom` 设置命名空间。它的 Cordis 行接受一个字段：

| 字段 | 默认值 | 范围 | 含义 |
|---|---|---|---|
| `zoomPercent` | `100` | 50–300 | 整体界面缩放百分比 |

如果你希望界面长期更大，直接在配置行上设置，而不是按快捷键：

```yaml
- id: ui-zoom
  name: '@suqingsq/dsh-ui-zoom'
  config:
    zoomPercent: 125
```

## 与「字号大小」的关系

两者互相独立，且是相乘关系。界面缩放 125% 配合 16 px 的会话字号，会话正文实际渲染约 20 px。设置行里写明了这一点，避免把两个控件混为一谈。
