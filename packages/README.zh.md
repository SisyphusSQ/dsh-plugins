# Packages

[English](README.md) | 中文

可独立安装的 DeepSeek Harness 插件。每个包有自己的 README、测试和验证记录。

已发布的 `0.2.0` 集合按 `@deepseek-ai/dsh@0.1.0-rc.6` 验证；仓库源码目标线为 `@deepseek-ai/dsh@0.2.0-rc.2`。2026-10-06 退役了五个包，下表是保留维护集。

| 包 | 能力 |
| --- | --- |
| [@suqingsq/dsh-ui-zoom](dsh-ui-zoom/README.zh.md) | Web 与桌面端的整体界面缩放，含设置页行与可按 profile 持久化的百分比 |
| [@suqingsq/dsh-session-tools](dsh-session-tools/README.zh.md) | 会话列表/读取/创建/重命名/Fork/relay 工具，以及 Web `@` 会话提及 |
| [@suqingsq/dsh-worktree-workspaces](dsh-worktree-workspaces/README.zh.md) | Git worktree 斜杠命令、模型工具、CLI 与 Web 弹层 |

协作与包边界约定见 [`AGENTS.md`](../AGENTS.md)。
