# DSH 0.2.2-rc.1 全插件适配实施计划

> **For agentic workers:** 按本计划逐包实施，先记录回归失败再修复；仓库与运行时边界优先于通用技能示例。

**Spec:** 用户 2026-11-05 明确要求把本仓库全部现存插件适配最新 DSH；最新版本以 npm dist-tags 与 GitHub Release 双重核实。
