| [dsh-codex-login-dock](dsh-codex-login-dock/README.zh.md) | Codex 订阅的会话登录卡、设置页与 Host 认证状态 |
| [dsh-openai-codex-oauth](dsh-openai-codex-oauth/README.zh.md) | ChatGPT 订阅 OAuth、token refresh、斜杠登录命令和 silent 浏览器登录 |
